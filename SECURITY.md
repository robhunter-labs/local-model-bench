# Security

This repository is a personal lab kit for testing the host and harness around a local model. It is not a security product, it ships no model weights, and nothing in it removes or weakens a model's safeguards. Run it only against systems you own or are authorized to test, with synthetic data. For a potential vulnerability in these files, use GitHub's private vulnerability reporting if enabled, or open a narrowly scoped issue without secrets or exploit details.
