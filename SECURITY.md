# Security

This repository is a personal lab kit for testing the host and harness around a local model. It is not a security product, it ships no model weights, and nothing in it removes or weakens a model's safeguards. Run it only against systems you own or are authorized to test, with synthetic data. To report a potential vulnerability or a sensitive problem in these files, use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it, and don't post secrets or exploit details anywhere public. If private reporting ever appears unavailable, email hello@robhunterworks.com.
